# Презентация и защитное слово к ВКР «MindFlow»

Материалы для защиты выпускной квалификационной работы.

## Файлы

| Файл | Содержание |
|---|---|
| [`index.html`](./index.html) | Интерактивная презентация · 25 слайдов · 10 графиков Chart.js |
| [`speech.md`](./speech.md) | Защитное слово · 25 разделов · приложение с ответами на вопросы комиссии |

## Просмотр

**Онлайн (после включения GitHub Pages):** [https://ekaterinagrisha.github.io/MindFlow/presentation/](https://ekaterinagrisha.github.io/MindFlow/presentation/)

**Локально:**

```bash
# В Finder
open index.html

# Или в терминале
python3 -m http.server 8000
# Затем http://localhost:8000
```

## Навигация по презентации

| Клавиша | Действие |
|---|---|
| `→` / `Space` / клик | Следующий слайд |
| `←` | Предыдущий слайд |
| `Home` / `End` | В начало / в конец |
| `F` | Полноэкранный режим |

## Регламент

Полный текст защитного слова рассчитан на ≈ 14–15 минут при академическом темпе. Для жёсткого десятиминутного регламента в `speech.md` приведены рекомендации по сжатию с указанием обязательных к произнесению цифр и слайдов.
