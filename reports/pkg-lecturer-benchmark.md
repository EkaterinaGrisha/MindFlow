# PKG-aware LECTURER benchmark

Замер: помогает ли передача профиля студента (`strong/weak/recent/goal`) в обычный prompt ментора LECTURER?

**Стенд:**
- 50 студенческих вопросов из того же golden set
- Top-5 чанков от Qwen3-Embedding-0.6B (cached)
- Имитация: вопросы задаёт реальный пользователь из БД с богатым профилем (`a67a43d8`)
- 2 ответа на вопрос: A=baseline LECTURER, B=PKG-aware LECTURER (получает блок ПРОФИЛЬ)
- DeepSeek-judge видит профиль + оба ответа, выбирает кто лучше подходит ИМЕННО этому студенту

**Профиль пользователя (использован для всех 50 ответов):**

```
ПРОФИЛЬ СТУДЕНТА:
• Цель обучения: Мой план
• Уже разобрался: Операции с матрицами, Ранг и базис, Собственные значения, Предел и непрерывность, Формула Байеса, Случайные величины, Сингулярное разложение (SVD) — часть 2, Производная и градиент.
• Путается / слабые места: диагонализируемость матрицы, собственные значения матрицы, линейная регрессия, матрица, матрица ошибок, roc-кривая, гомоморфизм, auc.
• Недавно спрашивал: «Запусти режим «Логическая цепочка»»; «Запусти режим «Угадай термин»»; «Предложи интерактивные задания».
Используй это: на сильных темах не задерживайся, на слабых — расскажи подробнее с примерами.
```

## Результаты

| Вердикт | Кол-во | % |
|---|---:|---:|
| ответ с PKG лучше подходит студенту | **41** | **82%** |
| baseline лучше | 9 | 18% |
| равноценны (TIE) | 0 | 0% |

✅ **PKG-aware LECTURER статистически помогает** (41/50 = 82% решающих сравнений в его пользу). Рекомендуется подключение в продакшен.

## Контекст: где PKG уже точно помогает

См. `reports/pkg-based-architecture.md` — генерация задач под слабые места (Slojl 3 PKG-архитектуры) дала **3:0:1tie** в пользу PKG. То есть PKG-сигнал работает в **активной генерации**, где модель должна выбрать ЧТО создать.

Этот бенчмарк измеряет другое: помогает ли тот же профиль в **пассивном объяснении темы**, где модель просто разворачивает retrieved_theory.

## Методика

1. Тот же golden set (50 пар), что в `reports/embedding-benchmark.md`.
2. Profile из `buildStudentProfile(a67a43d8)` — 8 strong + 8 weak + recent + goal.
3. Для каждого запроса 2 ответа DeepSeek-chat (LECTURER baseline vs LECTURER+PKG).
4. DeepSeek-judge видит профиль и оба ответа. Порядок A/B рандомизирован.
5. Метрика: процент побед PKG vs baseline vs ties.

Воспроизведение: `python3 infra/scripts/pkg_lecturer_benchmark.py --stage all`. Кеш в `pkg_lecturer_answers.json` и `pkg_lecturer_judges.json`.
